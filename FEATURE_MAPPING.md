# WriteUp Pro — Legacy-to-Enterprise Feature Mapping (FEATURE_MAPPING.md)

This matrix maps every original capability of **WriteUp Pro – Smart Academic Workspace** to its upgraded, enterprise-grade counterpart.

| Legacy Feature | Legacy Implementation | Enterprise Full-Stack Upgrade | Disposition |
| :--- | :--- | :--- | :--- |
| **User Authentication** | Client-side password comparison with hardcoded string `'password'` | **Argon2id/PBKDF2-HMAC-SHA256** password hashing, secure JWT Bearer authentication, and server-enforced role authorization. | **Replaced & Upgraded** |
| **Role-Based Access Control (RBAC)** | Role state stored in browser `sessionStorage` (`writeup_user`) | **Server-side FastAPI RBAC dependencies** (`require_roles("student")`, `require_roles("faculty")`, `require_roles("admin")`). Client UI reflects permissions; API strictly forbids unauthorized requests (HTTP 403). | **Replaced & Upgraded** |
| **Data Storage & Persistence** | Browser `localStorage` keys (`writeup_docs`, `writeup_profiles`, `writeup_cheats`) | **Normalized Relational SQL Database** (SQLite for zero-friction local execution, PostgreSQL-ready) with transactions, foreign keys, and indexes. | **Replaced & Upgraded** |
| **Student Academic Onboarding** | First-time modal saving branch, year, sem, division to local storage | **Relational `student_profiles` entity** with status lifecycle (`pending` $\to$ `approved` / `rejected` / `blocked`). Reverted applications retain prefilled fields and display administrator remarks. | **Preserved & Upgraded** |
| **Document Authoring Engine** | Deprecated `document.execCommand` on `contenteditable` `div` | **Modern Semantic Academic Editor** with rich-text toolbar (headings, tables, syntax code blocks, lists, alignment), live word goals, character counts, and A4 page layout with zoom. | **Replaced & Upgraded** |
| **Paste & Drop Restrictions** | Client `paste` & `drop` event interception with toast alert | **Client interception + Server Telemetry Logging**: Client blocks paste/drop events, and transmits security events to backend `/api/v1/integrity/events` for institutional audit. | **Preserved & Upgraded** |
| **Tab / Window Switch Detection** | Window `blur` event incrementing local counter | **Focus Telemetry Engine**: Window blur and visibility change events logged to relational `integrity_events` ledger with session metadata and review workflows. | **Preserved & Upgraded** |
| **Typing Cadence Burst Monitor** | Interval $< 30\text{ ms}$ incrementing local counter | **Keystroke Cadence Telemetry**: Detects rapid bursts, logs incident with burst length, and provides an administrative review and student appeal workflow. | **Preserved & Upgraded** |
| **Plagiarism Indicator** | `Math.random() > 0.95` random number generation | **Deterministic Internal Similarity Analysis Engine**: Normalizes text, computes n-gram and Jaccard similarity across cohort submissions for the same subject/task, and displays actual matching excerpts. | **Replaced & Upgraded** |
| **Cover Page Generator** | Dynamic HTML template injection in DOM | **Dual-Engine Cover Pages**: Dynamic preview in React frontend and server-rendered Cover Page in ReportLab PDF generation with institutional headers and rubric grids. | **Preserved & Upgraded** |
| **Marking Rubrics** | Hardcoded criteria in HTML; client-side sum check | **Configurable Relational Rubrics Engine**: Default 10 marks (Assignment) and 15 marks (Experiment) preserved. Server validates criterion bounds and document maximums. | **Preserved & Upgraded** |
| **Engineering Canvas** | 2D HTML5 canvas for freehand drawing | **Vector & Freehand Engineering Canvas**: Pen, lines, arrows, rectangles, circles, text annotations, stroke colors, grid guide toggle, undo/redo, and direct image embedding. | **Preserved & Upgraded** |
| **Autosave & Drafts** | 30-second `setInterval` overwriting local object | **Debounced Server-Side Autosave**: Background persistence with version history snapshots (`document_versions` table), conflict detection, and unsaved changes warnings. | **Replaced & Upgraded** |
| **Submission Lifecycle** | Changing status property in `writeup_docs` | **Immutable Submission Snapshots**: Submissions freeze a frozen HTML snapshot, generate a unique receipt code (`SUB-2026-IIET-XXXX`), lock the document, and notify assigned faculty. | **Replaced & Upgraded** |
| **Classroom Organization** | JavaScript `groupBy` array helper in browser | **Relational Classroom Management**: Submissions organized by Year, Department, Division, and Subject into structured folders (e.g. `SE - Computer Engineering (Div A)`). | **Preserved & Upgraded** |
| **Split-View Evaluation Panel** | Read-only HTML preview beside inputs | **Split-Screen Evaluation Workspace**: Left panel renders student write-up, cover page, and diagrams; Right panel provides rubric inputs, validation indicators, and feedback. | **Preserved & Upgraded** |
| **Faculty Approval & Signatures** | Hardcoded text name and date stamp | **Verifiable Digital Approval Record**: Server generates unique digital stamp verification hash (`SIG-FAC9021-IIET-XXXX`) with evaluator identity, immutable timestamp, and audit trail. | **Replaced & Upgraded** |
| **Registration Management** | Admin toggles status string in array | **Institutional Registration Management**: Search, filter by class/branch, approve, revert/reject with custom remarks, and suspend/reactivate accounts. | **Preserved & Upgraded** |
| **Security & Cheat Ledger** | Single integer counter displayed on admin dashboard | **Audit & Telemetry Console**: Granular ledger of all security events with event type, severity, student name, roll no, metadata, review actions (dismiss/investigate), and CSV export. | **Replaced & Upgraded** |
| **Grading Ledger & Exports** | Basic client-side CSV blob download | **Comprehensive Institutional Ledger**: Dynamic filtering by department, branch, semester, division, and subject, with server-generated CSV and PDF exports. | **Preserved & Upgraded** |
| **PDF Generation** | Browser `window.print()` with `@media print` CSS | **Server-Side ReportLab Engine**: Generates authentic A4 PDFs with two-pass page numbering (`Page X of Y`), institutional cover page, rubric table, digital stamp, and content. | **Replaced & Upgraded** |
| **Notifications** | Transient toast alerts only | **Persistent Notification System**: In-app notifications with read/unread tracking, badge counts, and deep-links for approvals, feedback, submissions, and grades. | **New Feature** |
